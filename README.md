# Zuta Technology — Portfolio

Official portfolio website for **Zuta Technology**, a software engineering
practice based in Benin City, Edo State, Nigeria.

## Stack
- HTML5
- Sass (SCSS) → compiled CSS
- Vanilla JavaScript (no framework)
- Font Awesome + Google Fonts

## Local Development

```bash
# If you want to edit SCSS:
npm install -g sass
sass --watch scss/styles.scss css/styles.css --style=compressed
